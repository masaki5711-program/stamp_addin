Excel / Word

便利アドインセット ダウンロード

Excel・Word のリボンから使える業務ツール集です。デート印(日付が自動で入る電子日付印)、シート差分比較、定型書式、定型文、ブック掃除、日付ツール(和暦変換・営業日計算)、お作法リセットの7ツール入りです。

stampset-setup.zip をダウンロード
Windows用インストーラー(管理者権限不要)

インストール手順(Windows)

  1. ダウンロードした zip を展開(解凍)する
  2. install.cmd をダブルクリックする
    (「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」)
  3. Excel / Word を再起動する
  4. ホームタブの右端に「便利ツール」ボタンが表示されます

動作要件

OSWindows(インストーラー使用時)
OfficeMicrosoft 365 版の Excel / Word(買い切り版 2016/2019/2021 は対象外)
ネットワークこのサーバーおよび appsforoffice.microsoft.com への接続

Mac・ブラウザ版(Office on the web)の方

インストーラーの代わりに manifest.prod.xml をダウンロードし、 Excel / Word(Web版)の「挿入」→「アドイン」→「自分のアドイン」→「マニフェストをアップロード」から登録してください。

使い方

  1. リボンの「便利ツール」ボタンでタスクペインを開く
  2. ホーム画面から使いたいツールを選ぶ(Excel専用ツールはWordではグレー表示になります)
  3. デート印は「デザイナ」タブで印を作成・保存し、セル/カーソル位置に押印。日付は押した日が自動で入ります

アンインストール

zip内の uninstall.cmd をダブルクリックして Excel / Word を再起動してください。
